# 问题现象

每次打开浏览器（Helium，Chromium 系）都弹出"为新建密钥环设置密码 / 解锁密钥环"。GNOME 或 KDE 上从来没见过这个弹窗。

# 结论

浏览器要把加密密钥存进 gnome-keyring，而这台机器有三块缺失：`gnome-keyring-pam` 包没装、`/etc/pam.d/login` 里没有调用 `pam_gnome_keyring`、`~/.local/share/keyrings/` 是空的（默认 keyring 从未创建）。GNOME 下这三步分别是 GDM 的 RPM 依赖、GDM 自带 PAM 配置、首次登录自动创建，所以 GNOME 用户感知不到。与登录方式无关——TTY 登录走的 `/etc/pam.d/login` 和 GDM 是同一套 PAM 机制。

# 解决方案

```bash
sudo dnf install gnome-keyring-pam
# /etc/pam.d/login 加两行（auth 区在 system-auth 之后、session 区末尾）：
# auth    optional    pam_gnome_keyring.so
# session optional    pam_gnome_keyring.so auto_start
```

首次弹窗时输入 TTY 登录密码（必须一致，PAM 靠"登录密码 = keyring 密码"静默解锁；别留空，留空是明文存储）创建 `login` keyring，重新登录一次即永不弹窗。

后续升级为图形登录（greetd + noctalia-greeter）后 PAM 文件换成 `/etc/pam.d/greetd`，Fedora 包已自带那两行。greetd 有个打包坑：包建的系统用户叫 `greetd`，而 `config.toml` 默认写 `user = "greeter"`（不存在），需改成 `greetd` 并修正状态目录属主、用 `GREETER_USER=greetd` 初始化。
