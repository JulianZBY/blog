# 一、数据类型与容器

## 1.1 序列 vs 非序列

| 类型 | 是否序列 | 有序 | 可索引 | 可变 |
|---|---|---|---|---|
| `str` | 是 | 是 | 是 | 否 |
| `list` | 是 | 是 | 是 | **是** |
| `tuple` | 是 | 是 | 是 | 否 |
| `range` | 是 | 是 | 是 | 否 |
| `set` | 否 | **否** | **否** | 是 |
| `dict` | 否 | 3.7+ 有序 | 按键访问 | 是 |

- **序列按定义就有序**，所以"所有的序列都是有顺序的"为真。
- 「字符串、列表、元组和集合都是序列，都能按索引访问」——**错**，集合不是序列，不能按索引访问。
- 集合迭代顺序**不保证**，所以 `for i in {1,2,3,4}` 的输出不一定是 `1 2 3 4`。

> [!warning] 字典的有序性（3.7 分水岭）
> Python 3.7 起字典**保持插入顺序**，打印顺序 = 创建顺序。因此
> - "Python 字典和集合都是无序的容器" → **假**（集合无序，字典有序）
> - "字典打印顺序与创建之初可能不同" → **假**
> 旧教材/旧题库按 ≤3.6 语义出题时，这两题答案会反过来，是同一批题里最容易和答案对不上的地方。

## 1.2 可变性

- 可变：`list`、`dict`、`set`
- 不可变：`str`、`tuple`、`int`、`float`

## 1.3 引用（别名）语义

`b = a` 只是**绑定同一个对象**，不是复制：

```python
a = [1, 2, 3]
b = a
a[0] = 4      # b 也变成 [4, 2, 3]
```

浅拷贝要显式写：`b = a[:]`、`b = list(a)`、`b = a.copy()`。
同理 `d1 = d` 之后 `d1["k"] = v` 会改到 `d`。

> [!note] `+=` vs `append`
> - `x += y`（列表）等价于 `x.extend(y)`，把 y 的**元素逐个展开**追加
> - `x.append(y)` 把 y **当成一个整体元素**追加
> 两者结果不同：`['p','y','t','h','o','n'] += [1,2,3]` → 9 个元素；`append([1,2,3])` → 第 7 个元素是列表。

## 1.4 元素类型与容量

- 列表元素**类型任意**，**不必相同**（"必须都是字符串/必须同类型"都是错的）
- 列表元素个数**受内存限制**，不是"无限个"
- 列表**支持比较运算符**（`>`、`<` 按元素逐个比较）

# 二、列表操作速查

## 2.1 索引与切片

```python
lst[0]        # 第一个，索引从 0 开始
lst[-1]       # 最后一个（第一个负索引是 -1，不是 -2）
lst[3:7]      # 下标 3,4,5,6 —— 结束位不含
lst[:-1]      # 去掉最后一个
lst[0:-1]     # 同上
lst[start:end:step]   # 三者可同正、同负、正负混合
lst[-1:-2]    # 空列表 []，不报错
```

`a = [1, 2, [3, 4]]`，`len(a)` 是 **3**，不是 4——内层列表算**一个**元素。

## 2.2 增删改查

| 操作 | 语义 | 注意 |
|---|---|---|
| `append(x)` | **尾部**追加 | 不是头部 |
| `insert(i, x)` | 下标 i 处插入 | 插入点之后的元素**索引整体后移** |
| `extend(it)` | 展开追加 | 等价于 `+=` |
| `lst + other` | 拼接 | 不是算术加 |
| `lst * n` | 重复拼接 | `[1,2]*3` → `[1,2,1,2,1,2]` |
| `del lst[i]` | 按**索引**删除 | |
| `pop(i)` | 删并**返回**下标 i 的元素 | 空参默认删**末尾** |
| `remove(v)` | 按**值**删除 | |
| `clear()` | 清空，保留对象名 | 与 `del lst` 不同 |
| `lst[i] = v` | 按下标赋值 | |

> [!tip] `del x` 与 `x.clear()` 的区别
> - `del x` 把**变量和对象本身**一起删除
> - `x.clear()` 只清空内容，对象名还在

## 2.3 排序与统计

| 写法 | 是否改原列表 | 返回值 |
|---|---|---|
| `lst.sort()` | **改**（就地） | `None` |
| `sorted(lst)` | **不改** | 新列表，默认升序 |
| `lst.reverse()` | **改**（就地反转） | `None` |
| `count(v)` | — | 值 v 出现次数 |
| `index(v)` | — | 首次出现的下标 |

> [!warning] 两个高频陷阱
> 1. 调用方式别记反：正确的是 `sorted(列表名)` 和 `列表名.sort()`。
> 2. `sorted()` 不改原列表，所以 `print(number)` 打印的仍是原顺序，只有 `print(result)` 是排好序的。
> 3. `reverse()` 只反转**顶层**，内层列表不反转：`[1,2,[3,4],5].reverse()` → `[5,[3,4],2,1]`。

# 三、字符串

- `list("hello")` → `['h','e','l','l','o']`，**不是** `["hello"]`
- `list('[1, 2, 3]')` → 拆成**单个字符**的列表 `['[','1',',',' ',...]`，**不是** `[1,2,3]`
- 字符 `* 2` 是**字符串重复**：`[i*2 for i in 'Python']` → `['PP','yy','tt','hh','oo','nn']`
- 字符串比较按 **Unicode 码点**（ASCII 是子集）：`#`(35) < `E`(69) < `a`(97)
- `"program" < "python"` → True（逐字符比到 `r` < `y`）

> [!danger] 字符串 + 数字
> `"身高是" + 180` → **TypeError（运行时错误）**，不是"语法错误"。要写成 `str(180)`。
> 这类题常把"运行时错误"和"语法错误"混着问，注意区分：
> - **SyntaxError**：语法/拼写层面，如漏冒号、用中文引号 `“”`
> - **TypeError / ValueError**：语法正确但运行时类型或取值不对
> - **IndentationError**：缩进不对

# 四、集合与字典

```python
s = {1, 2, 3}
s - {2}        # 差集，运算符 "-" 可用于集合差集
2 in s         # 成员判断，O(1)

d = {"color": "red", "shape": "circle"}
d["shape"]     # 按键取值
print("shape") # 打印的是字面字符串 "shape"，不是取值！
```

# 五、分支结构

```python
if cond:            # 条件后必须有冒号
    ...             # 靠缩进划分语句块，不用大括号
elif cond2:         # 不是 else if / elseif
    ...
else:
    ...
```

## 5.1 要点

- 分支用 **`if` / `elif` / `else`** 三个保留字；`in` **不是**分支保留字
- 实现**多路/多分支**的最佳结构是 **`if-elif-else`**
- `if` 能写单分支、`if-else` 双分支、`if-elif-else` 多分支
- 嵌套 `if` 中，`else` 与**其之前最近且尚未配对**的 `if` 配对（不是按缩进对齐猜，但实际按此规则）
- **分支结构不能向已经执行过的语句跳转**
- 条件链写法：`20 <= s < 50` 在 Python 中**合法**（等价于 `20 <= s and s < 50`）
- 三元表达式：`min = x if x < y else y`（不是 C 的 `x < y ? x : y`）

## 5.2 常见错误

```python
if x > 5 :
print("太大")        # ❌ 没有缩进 → IndentationError，if 没有语句块
```

```python
score = int(input())
if score > 60:
print("及格")        # ❌ 缩进错误，程序无法正常判断
print("不及格")
```

# 六、循环

```python
for i in lst:                    # 直接遍历元素
for i in range(len(lst)):        # 遍历下标
for i in range(a, b):            # [a, b)，不含 b
while True:
    pass                         # 合法，唯一的正确写法之一
```

递推累加，避免重复算阶乘：

```python
n = int(input())
f, s = 1, 0
for i in range(1, n + 1):
    f *= i
    s += f
print(s)          # n=3 → 9 (1+2+6)
```

> [!warning] `range()` 的参数必须是整数
> `for i in range(animal)`（animal 是列表）会直接 **TypeError**。

# 七、输入输出与格式化

## 7.1 输入

- **`input()` 返回字符串**，这是最高频的坑：

```python
x = input()        # "8"
if x > 5:          # ❌ TypeError: '>' not supported between 'str' and 'int'
```

必须先 `int(input())` / `float(input())`。

- PTA 多组输入读到文件尾：

```python
import sys
for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    ...
```

## 7.2 输出

```python
print(a, b)              # 默认空格分隔
print(e, end=",")        # 自定结尾；注意循环末尾也会带出分隔符
f"{x:.2f}"               # 保留 2 位小数
"{}".format(x)
"%.1f" % x
```

> [!danger] PTA 逐字符比对
> 输出多一个空格、少一个换行、行尾多余空格都算错。
> 典型：`print(''.join(f"{x} " for x in xs))` 结果 `"2 4 "` —— **行尾那个空格是题目要求的**。

## 7.3 浮点数陷阱

```python
2 == 2.0            # True（数值相等，与类型无关）
0.1 + 0.2 == 0.3    # False
(98.6 - 32) / 1.8   # 36.99999999999999，不是 37.0
```

`repr()` 用"最短往返表示"，所以 `98.6` 反算会露出误差。**输出格式化方式决定了评测成败**——这是本题目集里最容易和答案对不上的地方（见文末 7-2）。

# 九、标准库与保留字

| 模块/对象 | 用途 | 关键 API |
|---|---|---|
| `turtle` | 绘图 | `isvisible()`、`hideturtle()`、`isdown()`、`penup()`、`pendown()` |
| `matplotlib.pyplot` | 画图 | `import matplotlib.pyplot as plt` |

**保留字与标识符**

- 分支保留字：`if`、`elif`、`else`（`in` 不是）
- **`print` 是内置函数，不是关键字**
- 标识符**不能以数字开头**
- 标识符**大小写敏感**（`python` 和 `Python` 是两个名字）

# 十、易错点清单（本题目集实际踩到的）

1. **`input()` 返回字符串** —— 与整数比较/运算必先转换
2. **`sorted()` 不改原列表**；`sort()` 才改
3. **`del lst[i]`（按索引）vs `remove(v)`（按值）vs `del x`（删对象）**
4. **`append` 加尾部、`insert` 加任意位置** —— 题里常故意写反
5. **`x += y`（展开）vs `x.append(y)`（整体）**
6. **负索引 `-1` 是最后一个**；`lst[-1:-2]` 是空列表不是报错
7. **集合不可索引**；字典 3.7+ 有序
8. **`print` 不加引号是变量、加了引号是字面字符串**（`print("shape")` 打印 `shape`）
9. **`range()` 参数必须整数**
10. **缩进就是语法** —— 少一层缩进是 IndentationError
11. **"语法错误" ≠ "运行时错误" ≠ "缩进错误"**
12. **输出必须逐字符匹配**，含行尾空格
